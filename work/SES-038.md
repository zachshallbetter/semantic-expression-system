# SES-038 — Build a framework-neutral host adapter example

Status: Completed — host boundary example implemented

## Intent

Show how a host application can supply SES inputs and receive renderer-neutral output without moving application ownership into SES.

## Acceptance

- Application state is mapped through an explicit adapter.
- Resolver output remains renderer-neutral.
- Operation handoff preserves stable identity and identifies the host owner.
- Transport, persistence, authorization, navigation, and rendering remain named external seams.

## Evidence

- `tools/framework_neutral_adapter.py`
- `docs/conformance/host-adapter-fixture.json`
- `docs/24-protocol-neutral-adoption.md`

## Disposition

Accepted as a framework-neutral host adapter example. No framework, network, database, or product navigation is introduced.
