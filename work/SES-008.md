# SES-008 — Specify responsive invariants

Status: Completed — contract defined

## Intent

Define how responsive expression may change topology while preserving required content, operations, accessibility, priority, and reachability.

## Acceptance

- Reorder, collapse, hide, transform, overflow, and clip rules are explicit.
- Required responsive invariants and failure conditions are named.
- Wide, narrow, small-touch, reduced-motion, and high-contrast contexts are covered.
- No breakpoint values, CSS, renderer, or host layout is implemented.

- `docs/conformance/responsive-invariants.json`

## Disposition

Accepted as a responsive expression contract. Runtime evaluation remains future validator work.
