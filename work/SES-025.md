# SES-025 — Implement token and asset resolution

Status: Completed — pure resource resolution implemented

## Intent

Resolve caller-supplied token and asset registries deterministically while keeping retrieval, decoding, capability discovery, and host execution outside SES.

## Acceptance

- Token lookup follows the declared layer order and records provenance and alias path.
- Token cycles and missing references produce typed failures.
- Asset lookup requires the declared category and valid metadata.
- The resolver emits resolved resource metadata when registries are supplied.
- No file, network, or host resource loading occurs.

## Evidence

- `tools/resource_resolution.py`
- `tools/ses_resolver.py`
- `docs/conformance/resource-fixtures.json`

## Disposition

Accepted as pure token and asset resolution. Full recipe precedence and projection enforcement remain SES-026 and SES-027.
