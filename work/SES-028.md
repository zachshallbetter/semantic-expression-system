# SES-028 — Add deterministic serialization and snapshot comparison

Status: Completed — canonical snapshots implemented

## Intent

Create reproducible output snapshots for resolved SES values without relying on insertion order or host formatting.

## Acceptance

- Object keys are explicitly ordered before serialization.
- Serialization encoding and digest algorithm are declared.
- Equivalent values with different object insertion order produce the same digest.
- Changed values produce a different digest.
- Snapshot comparison reports expected and actual digests.

## Evidence

- `tools/deterministic_snapshot.py`
- `docs/conformance/snapshot-fixtures.json`

## Disposition

Accepted as deterministic snapshot infrastructure. Snapshot governance and mutation coverage remain later qualification work.
