# SES-030 — Verify semantic identity across multiple expressions

Status: Completed — three-expression equivalence verified

## Intent

Demonstrate that radically different Visual Languages can resolve the same semantic target and operation identity.

## Acceptance

- At least three distinct Visual Languages resolve from one semantic input.
- Composition/target identity is identical across outputs.
- Operation identity is identical across outputs.
- Expression records differ in morphology and declared presentation mutations.
- A changed identity or operation causes verification failure.

## Evidence

- `tools/verify_expression_equivalence.py`
- `docs/conformance/expression-equivalence-fixtures.json`

## Disposition

Accepted as semantic identity equivalence coverage. Accessibility and host behavior are verified by later issues.
