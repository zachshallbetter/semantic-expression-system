# SES-015 — Establish change governance

Status: Completed — governance defined

## Intent

Make SES evolution traceable, compatibility-aware, conformance-reviewed, and explicit about deprecation and version boundaries.

## Acceptance

- Independent version boundaries and change classes are defined.
- Normative change records have required fields.
- Conformance-impact review inputs are explicit.
- Deprecation and changelog requirements are explicit.
- Missing evidence cannot be treated as a pass.
- No external release or publication action is taken.

## Evidence

- `docs/20-change-governance.md`
- `docs/conformance/change-governance.json`

## Disposition

Accepted as a local governance contract. External release authority remains unassigned.
