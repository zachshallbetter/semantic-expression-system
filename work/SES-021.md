# SES-021 — Implement a minimal pure resolver

Status: Completed — local reference resolution implemented

## Intent

Provide the first executable semantic-to-expression boundary without implementing a renderer, asset loader, operation runtime, or application behavior.

## Acceptance

- `tools/ses_resolver.py` exposes a pure resolver over already-loaded values.
- The resolver preserves semantic composition identity and operation identity.
- The output contains the renderer-neutral sections required by SES-014.
- Invalid or mismatched targets produce typed failures.
- The reference CLI performs no external effects beyond reading explicit local fixtures and writing stdout.

## Evidence

- `tools/ses_resolver.py`
- `tools/resolve_reference_fixture.py`
- `docs/conformance/reference-pack/media-card.json`
- `docs/conformance/reference-pack/appearance-neo-edo.json`

## Disposition

Accepted as the first local implementation. Token lookup, asset loading, full recipe precedence, validation, and host rendering remain separate issues.
