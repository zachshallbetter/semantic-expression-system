# SES-011 — Define recipe precedence and conflict handling

Status: Completed — contract defined

## Intent

Make Recipe combination deterministic while preserving semantic authority across Visual Language, Theme, state, variant, responsive, accessibility, and local expression layers.

## Acceptance

- Precedence order is fixed and machine-readable.
- Scalar, object, ordered-array, Slot, State, Variant, and protected-field merge behavior is explicit.
- Same-precedence conflicts and protected-field overrides fail without fallback winners.
- Resolved layer trace requirements are defined.
- No resolver or renderer implementation is added.

## Evidence

- `docs/17-recipe-precedence.md`
- `docs/conformance/recipe-precedence.json`

## Disposition

Accepted as a precedence contract for the SES-004 resolver boundary.
