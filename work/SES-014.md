# SES-014 — Define renderer-neutral output contract

Status: Completed — contract defined

## Intent

Specify the resolved projection handed from SES resolution to any host renderer without coupling SES to DOM, CSS, native widgets, canvas, or a framework.

## Acceptance

- Output sections for identity, semantics, projection, expression, resources, interaction, accessibility, responsive behavior, trace, and diagnostics are explicit.
- Host-neutrality rules and namespaced extension boundaries are explicit.
- Semantic/expression separation, provenance, determinism, and required metadata invariants are explicit.
- Typed output failures are defined.
- No renderer or host adapter is implemented.

- `docs/19-renderer-neutral-output.md`
- `docs/conformance/renderer-neutral-output.json`

## Disposition

Accepted as the renderer boundary for SES-004.
