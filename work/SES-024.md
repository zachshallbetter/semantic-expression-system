# SES-024 — Add negative-fixture execution and typed diagnostics

Status: Completed — declarative negative-fixture execution added

## Intent

Execute the existing negative-fixture records as expected failures and preserve their baseline, layer, error code, path, and failure condition.

## Acceptance

- Every negative fixture has a unique ID and required failure metadata.
- Each valid record emits `result: fail` with its declared typed diagnostic.
- Malformed records emit `result: blocked` with `ERR_NEGATIVE_FIXTURE_MALFORMED`.
- The output is deterministic JSON and exits non-zero only for malformed fixture input.

## Evidence

- `tools/execute_negative_fixtures.py`
- `docs/conformance/fixtures/negative.json`
- `docs/10-validator-contract.md`

## Disposition

Accepted as declarative negative-fixture execution. Runtime semantic mutation and host evaluation remain later validator work.
