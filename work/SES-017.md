# SES-017 — Define performance budgets

Status: Completed — provisional budgets defined

## Intent

Bound SES resolution and renderer-neutral output costs while preserving semantic, accessibility, operation, and responsive invariants.

## Acceptance

- Resolution, token lookup, asset metadata, layer/depth, responsive recomputation, motion metadata, and output-size budgets are defined.
- Measurement boundaries exclude resource and host work from pure resolver timing.
- Required semantics may not be dropped to meet a budget.
- Measurement fields, degradation rules, and typed failures are explicit.
- Budgets are marked provisional until runtime evidence exists.

## Evidence

- `docs/22-performance-budgets.md`
- `docs/conformance/performance-budgets.json`

## Disposition

Accepted as a provisional performance contract. Qualification requires measurements from an implementation profile.
