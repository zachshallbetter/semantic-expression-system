# SES-006 — Define conformance result format

Status: Completed — format defined

## Intent

Make conformance outcomes machine-readable and traceable to a baseline, fixture, check, failure condition, and evidence record.

## Acceptance

- Result records require baseline ID, fixture ID, layer, check ID, result, severity, and evidence.
- Failed and blocked results require typed failure codes and conditions.
- Inconclusive results require a summary and retain limitations.
- Expected and observed values and source paths can be recorded when applicable.
- The format does not claim a pass when an evaluator is unavailable.

## Evidence

- `docs/conformance/result.schema.json`
- `docs/conformance/results/SES-002-structural.json`

## Scope boundary

This issue defines the result envelope only. It does not implement a validator, renderer, evaluator, or promotion workflow.
