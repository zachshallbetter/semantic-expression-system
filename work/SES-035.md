# SES-035 — Add reduced-motion and high-contrast handling

Status: Completed — accessibility mode handling implemented

## Intent

Adapt expression metadata to user accessibility preferences without changing semantic identity or operation identity.

## Acceptance

- Reduced-motion context disables motion and uses a declared fallback.
- Missing reduced-motion fallback fails.
- High-contrast context requires an explicit high-contrast expression.
- Accessibility context is retained in output metadata.

## Evidence

- `tools/accessibility_modes.py`
- `docs/conformance/accessibility-mode-fixtures.json`
- `docs/15-accessibility-expression.md`

## Disposition

Accepted as pure accessibility-mode expression handling. Host media-query and assistive-technology execution remain later qualification work.
