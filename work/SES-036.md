# SES-036 — Add security validation for assets and executable expression inputs

Status: Completed — expression trust-boundary validation implemented

## Intent

Keep expression inputs data-only and reject unsafe resource sources or unnamespaced custom capabilities before resolution or rendering.

## Acceptance

- Executable expression keys fail with typed diagnostics.
- Unsafe and unsupported asset source schemes fail.
- Custom sources require an explicit namespace.
- Valid fixture and asset sources pass.
- No source is fetched or executed by validation.

## Evidence

- `tools/security_validation.py`
- `docs/conformance/security-fixtures.json`
- `docs/21-security-trust-boundaries.md`

## Disposition

Accepted as input trust-boundary validation. Host capability, network policy, and asset scanning remain outside this pure check.
