# SES-018 — Define authoring boundaries

Status: Completed — boundaries defined

## Intent

Route each SES concern to one canonical authoring surface so semantic meaning, expression freedom, host realization, and application behavior do not compete for authority.

## Acceptance

- Ownership for semantic, projection, expression, resolver, host, and external protocol surfaces is explicit.
- Routing rules distinguish stable properties, mutable presentation, data movement, and business behavior.
- Host extensions require namespace and provenance.
- Conflicts resolve to canonical semantic/Projection Contract authority or remain explicitly unresolved.
- No repository reorganization or application behavior change is performed.

## Disposition

Accepted as an authoring and authority-routing contract.
