# Support

SES has a solo maintainer, so support is best-effort with no SLA.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/semantic-expression-system/issues/new/choose).
- **Security reports:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Versions:** releases are tagged `vX.Y.Z`; what changed in each is in [docs/CHANGELOG.md](docs/CHANGELOG.md).
  Fixes go into the latest release.
