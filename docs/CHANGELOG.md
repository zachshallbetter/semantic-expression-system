# Changelog

## 1.0.0 Draft Standard

- Renamed the umbrella architecture to Semantic Expression System (SES).
- Defined Component as an implementation term rather than an SES semantic layer.
- Added explicit Operation semantics.
- Upgraded Socket to a typed participation and projection boundary.
- Added Projection Contract between semantic structure and expression.
- Added typed invariance for semantic, behavioral, action identity, structural, morphological, and visual properties.
- Added Morphology as a first-class expression layer.
- Replaced atomic surface, edge, texture, and ornament assumptions with layered Appearance Recipes.
- Added full and custom backgrounds, texture layers, pattern layers, targeted edges, multiple edge layers, decoration, masks, clips, bleed, compositing, and z-order support.
- Defined token layers: primitive, semantic, role, recipe, resolved.
- Defined asset registries for fonts, icons, textures, patterns, masks, edges, backgrounds, ornaments, and custom resources.
- Added resolver cascade and host-neutral renderer boundary.
- Added layered conformance and negative fixtures.
- Added independent implementation and protocol boundary for downstream projects such as IV.
